# Core milestones and retained Full scope

The Core roadmap runs beside the [preserved Full roadmap](PSCV0_NATIVE_IMPLEMENTATION_ROADMAP.md). It neither rewrites old acceptance nor requires all advanced Full exits before the compiler workload advances. The authority remains selected v7.2. A missing workload feature requires an owned implementation or a reviewed source conversion; native spelling does not implicitly extend the selected grammar.

Every exit freezes the capability and source manifest: all authoritative compiler modules, required checked declarations, generated helpers, registrations, runtime dependencies and applicable targets. Exclusions have explicit reasons. Source counts, passing examples and import reachability alone cannot close an exit.
