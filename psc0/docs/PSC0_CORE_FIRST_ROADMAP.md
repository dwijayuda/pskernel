# Core milestones and retained Full scope

The Core roadmap runs beside the [preserved Full roadmap](PSCV0_NATIVE_IMPLEMENTATION_ROADMAP.md). It neither rewrites old acceptance nor requires all advanced Full exits before the compiler workload advances. The authority remains selected v7.2. A missing workload feature requires an owned implementation or a reviewed source conversion; native spelling does not implicitly extend the selected grammar.

Every exit freezes the capability and source manifest: all authoritative compiler modules, required checked declarations, generated helpers, registrations, runtime dependencies and applicable targets. Exclusions have explicit reasons. Source counts, passing examples and import reachability alone cannot close an exit.

| Milestone | Core responsibility | Falsifiable exit |

| M4 | Core execution/control and proof-contract/assurance boundaries | Except/Id/local state/traversal preserve results, errors and evaluation order; remaining loops are supported or checked-converted; host IO is an explicit adapter; ordinary execution cannot acquire unavailable verified/model/refinement identity |
| M5 | Incremental compilation, code generation, optimization, tooling, reproducibility and reconstruction | Entire authoritative Core compiler passes Stage2 and Stage3; complete identity keys make cold/warm/incremental products agree; applicable target artifacts execute against the same reference workload; reconstruction and provenance meet the declared comparison contract |

No Core milestone is currently marked complete. A green isolated seam has its own bounded receipt.
