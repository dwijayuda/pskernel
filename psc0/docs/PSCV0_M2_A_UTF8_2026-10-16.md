Select String.toUTF8, String.fromUTF8? and ByteArray.validateUTF8. PSC0 currently has an audited opaque String primitive model and a checked ByteArray record over Array UInt8; do not import native String projections against a different logical representation or introduce new axioms. Construct total checked definitions over existing audited String/Char operations and checked ByteArray/Nat/Bool/Option. Traverse using input byte count as a structural bound, not compiler fuel. A shared logical width/code/validity decomposition rejects continuation leads, C0/C1/F5..FF, truncated sequences, overlong forms, surrogates and scalars above U+10FFFF. Public fromUTF8? returns none on every malformed input. No replacement-character decoding, BOM removal, Unicode normalization or NUL termination.

Executable lowering uses exactly three typed array/string primitives: encode, validate and total decode (empty on invalid). ByteArray wrapping/projection and Option construction remain ordinary checked code. The decoder's invalid behavior is total even if reached outside the public validity guard. No raw bytes become a trusted string without validation. Backend native paths are linear builders: shared ECMAScript TextEncoder/fatal TextDecoder with ignoreBOM=true; safe Rust std::str::from_utf8; GC Wasm reuses one strict validator/count implementation with explicit ABI trapping wrappers. GC buffers remain internal; only existing ABI boundaries use linear memory.

Signature matching, kernel model admission and runtime differential observations are separate evidence. This selected logical model does not claim native String/IsValidUTF8 inductive identity or a general encode/decode equivalence theorem. Public proof-taking String.fromUTF8 and native theorem-family closure require the later representation/proof-surface decision, not fabricated proof evidence.

Qualification should use one compact shared valid/invalid vector corpus against native Lean, all emitted targets and existing component round-trips: empty, NUL, ASCII, 2/3/4-byte boundaries, BOM, maximum scalar, overlong, isolated continuation, missing/bad continuations, surrogate and out-of-range sequences; persistent byte input and partial application. Reuse existing backend observation harnesses and ABI checks.

## Prepared implementation boundary

The in-memory draft includes 11 checked logical definitions, three typed IR operations, nominal ByteArray lowering, shared structured ECMAScript helpers, safe Rust helpers and a GC Wasm codec with one nontrapping validator. Canonical ABI input reuses that validator and retains its trap-on-invalid contract. The i64 count/-1 result avoids collision with any valid u32 byte length. No new axiom or class instance is selected. Nineteen independent native valid/invalid vectors drive 48 shared runtime observations, including persistent inputs, partial decoding and byte-exact roundtrips.
