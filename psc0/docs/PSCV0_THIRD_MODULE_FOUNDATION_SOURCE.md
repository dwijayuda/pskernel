# PSCV0 v7 — Third compiler-source feasibility candidate: Ps.Foundation.Source

**Status:** source candidate authored, compiler-only differential pending. Development branch: psc0/pscv0-compiler-fast-loop-v1. The sole future ProofScript language authority is [PSCV0 v7](../PSCV0_LANGUAGE_REFERENCE.md).

This is deliberately a **different feature family** from the existing generic-recursion List module. The immutable Lean baseline at packages/foundation/src/Ps/Foundation/Source.lean contains exactly **two structures**, PsSourcePos and PsSourceSpan, in eight physical lines. The new candidate at packages/foundation/src-ps/Ps/Foundation/Source.ps has the same named structure declarations in ten physical lines and uses v7's required braced structure field grammar. Neither code base nor kernel model is modified; only an alternative authored source is added.

The [manifest-driven multi-module compiler differential](../tools/abi/compiler-source-differential.mjs) is now the *single reusable test architecture*, instead of adding another module-specific test script. It reads the exact v7 source manifest [pscv0-fast-candidates.json](../pscv0-fast-candidates.json) and, for each candidate, uses the cached generated PSCV0 JS parser and the retained PSC0 compiler. It checks source syntax/AST and exact declared API count, reconstructs the receiving runtime's source AST, elaborates both the new source and the original Lean baseline, and compares **canonical admission bytes and TypeScript 7 output bytes**. Any mismatch fails with its first semantic/target difference; no test expectations are patched to force acceptance.

The only gate executed is **compiler-package typechecking/elaboration and target emission**. No independent kernel checker, kernel proof suite, verified executable certification or new compiler fixed-point cycle is requested. A successful differential is bounded compiler product equivalence for that exact source/compiler identity, **not** broad v7 conformance. After validation, the remaining step is deliberate promotion of additional authored sources into a new generated compiler closure, with fresh source and release receipts rather than inheriting historical first-module qualification.
