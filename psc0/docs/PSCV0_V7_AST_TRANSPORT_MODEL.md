# PSCV0 v7 — Formal Contract for Cross-Bundle Source AST Transport

**Status:** abstract specification and proof target; **not a formal verification of the JavaScript codec or PSC0 compiler**. Repository: `dwijayuda/pskernel`; branch `psc0/pscv0-v7-abi-model-v1`; date 11 October 2026.

The actual generated PSCV0 frontend and retained compiler emit fresh private JavaScript ADT-tag symbols in different module instances. Directly sharing those objects caused [38125532982](https://github.com/dwijayuda/pskernel/actions/runs/38125532982) to fail. The [closed concrete source-AST converter](../tools/abi/transport.mjs) reconstructs recipient-owned algebraic data types, refusing unknown source constructors and source schema/owner mismatches while leaving full elaboration, checked admissions and kernel acceptance mandatory.

The abstract Lean specification [ASTTransportModel.lean](../test/pscv0/reference/ASTTransportModel.lean) defines a small, source-only term syntax with **atoms, ordinary applications, and parenthesized groups**. Its wire form admits an additional invalid constructor. A tagged packet records source-owner domain and schema revision; `transfer` checks that the packet belongs to the generated source runtime and revision 7, deserializes the source syntax, and reconstructs a recipient-runtime packet.

The nine intended theorem obligations cover: (1) well-formed encode/decode identity, (2) correct successful ownership transfer, (3) foreign-origin refusal, (4) wrong-revision refusal, (5) direct invalid-constructor refusal, (6) nested invalid-constructor refusal, (7) transfer replay refusal, (8) `f x(y)` versus `(f x)(y)` source-grouping distinction, and (9) grouped source preservation. The dedicated CI must verify all with **no axioms** on exactly Lean 4.35.0-rc4 commit `c29b6dda4f7c20e3eeaa717c4e565663c5cfa364`. No CI conclusion is claimed before the actual run completes.

**Boundary of the proof:** these are constructor-level properties of an independent abstract model, not machine-checked proofs of `psc0/tools/abi/transport.mjs`, the self-hosted compiler, the TypeScript emitter, Windows runtime, kernel consistency or full PSCV0 v7 language semantics. In particular, the operational interop adapter checks a much richer AST: lists, options, binder telescopes, declarations, patterns, records, source positions, budgets and exact runtime tag identities. Refinement evidence between that implementation and this model remains an independent future obligation; passing model proof cannot replace generated Linux/Windows and independent checked-kernel tests.

Source-language authority stays the sole [PSCV0 v7 reference](../PSCV0_LANGUAGE_REFERENCE.md), SHA-256 `843940bd7f6a9b286e80b01d8c891a7e01b8868a9de7b05833fce32d49be6cd5`. No older `.ps` grammar compatibility or new kernel constructors are introduced.
