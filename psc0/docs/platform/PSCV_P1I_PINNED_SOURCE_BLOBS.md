# PSCV P1-I — immutable Lean module source blobs and lexical candidates

The qualified P1-H Lean environment probe identifies three imported
module names for eleven selected constants:
`Init.Prelude` (9), `Init.Data.String.Defs` (1),
`Init.Data.Int.Basic` (1).

P1-I checks the exact **Lean4.35.0-rc3 Git commit**
`470d5ce1400764999581fd26d5d72b00d990b0f4`,
then reads only these three exact upstream source files as Git blobs.
Their Git SHA-1 identities are pinned independently of checkout newline
conversion. It looks for unique explicit textual
`instance selectedConstantName ...` declaration lines, where present.
Other selected constants may be generated by elaboration or anonymous
instance syntax; their lexical line remains null rather than guessed.

This is source-provenance *candidate* evidence: a typed imported constant
and a same-named textual instance line in the pinned module is not yet
a formal source-to-Core elaboration proof, priority/tie search proof,
or approval to enter PSCV Standard. Exact import scope, dependency
instantiation, theorem/operation models, all other required Standard
registries and WP/verification effects remain to be qualified.

The source work ledger still contains **230 normative rows / 194 IDs**;
three direct Boolean locations were previously identified in P1-C,
and **191 Standard ID mappings remain unresolved**. P2–P5 continue under
[the sound gates](PSCV_P1_TO_P5_SOUND_GATES.md), with production
certificate issuance unavailable.

This work modifies no bootstrap/compiler/kernel algorithm or selected
release and does not publish an npm package.
