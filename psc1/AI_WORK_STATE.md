## Protocol and authority

Scalar requests remain seven-cell `psc1-compiler-service/1`.
Explicit IO requests are eight-cell `psc1-compiler-service/2`, ending in literal
`io-dispatcher`. Successful candidates require the selected exact protocol,
fields, request/source identity, target and ABI. Refusals keep the existing
candidate-only envelope. An IO candidate cannot enter a scalar session.

The API/CLI option is host-selected. Project JSON stays sources/entry/assurance
only. `proofscript/io` reuses existing typed-io.mjs with explicit Linux ABI,
capabilities/root/byte/fd limits and preflight before program loading.
Checked output remains JS; candidate JS/TS/Rust mappings grant no admission or
publication authority. Wasm callback-output refuses explicitly; preserved native
Wasm String IO remains separate. Python/PHP stay optional; all seven native
backend mappings retain their regression coverage.
