# Remaining Practical Core v1 acceptance

This change supplies executable evidence for the twelve remaining frozen
criteria. The scope remains fourteen families, 37 criteria, both source
grammars, seven backends and four finite applications. New bindings are
implemented eligibility, not qualification before exact Linux CI.

| Criteria | Required execution and companion evidence |
| --- | --- |
| for collections | collectionControllerCase: list/Array order, empty input, CompilerM state and typed error; native source-expression evaluation count |
| for ranges | rangeControllerCase: lower-inclusive/upper-exclusive, equal/reversed endpoints; native endpoint calls each occur once |
| for streaming | streamingControllerCase: 100000 complete actions and immediate return from a range ending at 10^18; retained measured compiler application |
| while controller/divergence | existing eight-case ordinary Id/Except corpus in both accepted grammars, all seven targets and minimum Python; selected nesting, mutation/return/errors, strict external deadlines and all sixteen profile refusals |
| partial pairing/recursion | direct/non-tail/higher-order cases on all targets; independent native opaque-witness, exact-body pairing, forged-admission/changed-body/axiom/uninhabited-result refusals |
| product patterns/identity | tupleProductsCase: Unit, grouped/nested/wildcard patterns, old closure identity and original RHS scope; complete native data scope tests and genuine pattern-divergence deadlines |
| Array operations | empty/literal/push/set/map/fold and persistence against a separate native standard-Array implementation; receiver/index call counts and wrong-element/index/map refusals |
| namespace identity/ownership | nested/reopened/dotted/current/enclosing/root/local precedence case; native canonical identity/translation tests and complete existing privacy/publication-preservation boundary receipts |

The ordinary while corpus retains the selected v1 profile and explicit
refusals. Selected nesting includes while inside finite for and sequential
while controllers. Wider nested bodies, CompilerM while and unsupported result
profiles remain outside that selected slice, as already specified by
PSC1_PRACTICAL_CORE_DECISIONS.md. No refusal is relaxed. Its PS corpus is the
owned canonical translation of the authored Lean corpus; the new finite
inference/control cases independently author both source surfaces.

The shared inference/control suite grows from ten to eighteen cases
(252 complete case/grammar/target obligations). The independent collection
suite grows from three to four (56 obligations). All old cases/refusals remain.
The private recursive source graph requires explicit ordinary assurance;
verified requests still refuse.

Native evaluation tests count original collection, range endpoint and Array
receiver/index calls in independently admitted Core and execute both flag
paths. Native suite inventory retains source and log hashes. Runtime equality
alone cannot replace these ownership checks. Pattern identity additionally
requires real two-second external deadlines on all targets and minimum Python.
Streaming additionally requires the actual twelve-case, 100000-statement
compiler application and its unchanged time/RSS acceptance.

Existing while tests acquire explicit source/admission/artifact identities and a
strict receipt checker, preserving the same compiler executions and negative
tests. The checker rejects stale identities, duplicate/missing source/target
pairs, skipped observations, wrong exported names, changed resource deadlines
and absent profile refusals. Native, privacy, strictness and measured-application
companions are mandatory for the corresponding readiness criteria.

Every criterion is now bound, but releaseReady remains false until actual
complete exact-commit evidence passes. Require the full scoped matrix and
manual Practical Core release qualification before calling feature freeze
complete. No merge, registry publication, unrestricted language conformance,
formal backend preservation or G2/G3 result follows from a data receipt.

Once every finite criterion is bound, the normal complete matrix also invokes
the readiness checker with --full-qualification and requires releaseReady=true.
The existing manual release wrapper still requires --require-ready. This adds
a data-contract assertion to the already executed matrix, not another expensive
test replay. Focused development tiers and deferred manual G2/G3 stay unchanged.
