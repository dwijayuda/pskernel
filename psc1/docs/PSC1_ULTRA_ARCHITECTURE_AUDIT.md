## Architecture and assurance

Both parsers produce `PsSyntaxModule`; one elaborator produces canonical Core. The active CLI captures dependency text/ownership, independently admits canonical logical declarations with official Lean, erases the same immutable graph, validates typed executable IR, builds target plans, validates actual target output and publishes a sealed generation atomically. Ordinary partial execution additionally recomputes the exact constructive opaque-witness/checked-body companion graph. Six closed target paths specialize; Rust retains checked generic IR.

The owned PSKernel-Core is separately tested and is not the authoritative active direct provider. Canonical nested-inductive admissions use checked shallow-recursor wrappers; identify the exact normalized canonical graph rather than implying every raw source serialization is identical. Logical admission, IR typing, actual execution and formal behavioral preservation are distinct. Verified execution still refuses; no preservation theorem is established by these tests.

## Highest-value architecture choices

Preserve one shared Core/typed expression IR. Typed lets, calls, branches, matches and data can already encode state and typed control; no evidence justifies a wholesale SSA replacement. First make handler composition correct, close measured indexing/continuation problems and unify Rust owned closure values. Revalidate every transformed IR and keep target ABI checks distinct from internal language support.

Keep runtime helpers with backend packages and formatting/publication in the explicit host boundary. A directory outside `packages/` is not a missing dependency when the installed native package already ships it. JS/TS outputs are printed independently and formatting is AST-checked; Rust is Cargo/rustfmt validated; WAT comes from actual binaries; Python/PHP syntax is checked with honest declaration-start origins.

Measure before declaring a performance redesign complete. Baseline/replacement workloads must include repeated array access, early-return huge finite loops, deep syntax/data sharing and callback-heavy compiler code. Record time/memory/work counters, exact commits and same-tool workloads. These notes contain no invented performance measurements.
