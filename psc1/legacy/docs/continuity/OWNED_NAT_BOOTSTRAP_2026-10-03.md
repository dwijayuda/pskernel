# Owned Nat bootstrap checkpoint

Integration base: `bfab5af09c8269654410ec9f4ceaceb008dcfbe0`.
Package: `@proofscript/pskernel-core@0.1.0-checker.7` (private, experimental,
not authoritative). The owned kernel remains the default and part of bootstrap.
Lean WASM and native Lean remain explicit reference alternatives outside the
portable closure. Rejection, unsupported input, failure and exhaustion never
select another checker.

## Semantic change

Generated source now checks monomorphic, zero-parameter, zero-index inductives
in `Type` with exactly two ordered constructors: `zero : F` and `succ : F -> F`.
It checks the family and both constructor types, derives the dependent recursor,
and implements zero/successor iota reduction. Recursor metadata is generated by
the owned checker; ordinary definition admission cannot introduce it.

The generated bootstrap starts with an empty environment and submits the fixed
`Nat`, `Nat.zero`, `Nat.succ` declaration to that same machine. Only after this
check succeeds does it begin user declarations. Prelude checking, name lookup,
type checking, conversion and reduction share the outer transition budget.
An empty user module still pays for Nat initialization. The host performs wire
conversion and bounded driving; it supplies no assumed Nat environment.

This adds neither natural-number literals nor arithmetic primitives. Other
prelude declarations, general constructor fields, term parameters, indexed and
mutual families, nested/higher-order recursion, proof irrelevance and eta remain
unfinished. The actual compiler prefix still stops at `PsSourcePos`, whose three
Nat fields require record constructor admission. Its preceding unit declaration
passes, and Nat itself is now available through owned checking.
