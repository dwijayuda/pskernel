## Implementation boundary

The public DAG entry derives a fresh private owner set from the session's already admitted declarations. It accepts no caller-supplied owner table or receipt. Canonical input nodes seed exact environment-index lookups; checked types, transparent definition bodies, family metadata and recursor rule bodies extend the demand closure. Literal translation and the Nat Boolean results add their implicit helper names.

The importer uses one private appended arena. Original caller input IDs continue to address the original decoded input. Newly imported type, value and rule IDs stay private. The admitted declaration list supplies only a structural termination bound: one cons is consumed per new unique owner, and the list head is never declaration authority. Empty demand checks one outer list constructor and returns without walking its tail. There is no environment-size prepass or eager import of unrelated declarations.

After a successful command, the existing T03a final-prefix/Quot bridge remains intact. Demand completion visits the newly appended metadata using the actual next checked environment. The environment identity and operation-local caches remain attached to the owning state; separate public calls reconstruct owners from their own immutable session. Failed import or a later command publishes no partial session, owners or replies.

This adapts admitted state. It does not add another admission mechanism or replace V1 ordinary, mutual, nested or Quot admission. Low-level forged internal sessions and owner records remain within the documented trusted integration boundary.
